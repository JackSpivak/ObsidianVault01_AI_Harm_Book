# Circumstance, Situation, Description and Networks

## Why this is distinct
- It gives a formal chain: circumstance is a collection of events, a situation is a subset of circumstances that satisfies a description, and the description is itself part of a network. It also asks which schema should represent ordinary reality.

## Anticipated direction
- Define events, circumstances, situations and descriptions as separate classes, with satisfaction as the link between a situation and a description.
- Represent the networks that connect descriptions, and test whether a standard schema (such as schema.org) can carry them.

## Conceptual territory
- Feeds the situation and horizon work in [[Participation Threshold and Distance from Harm]] and the originating circumstance placeholder in the Harm Ontology's Event class.
- Related to [[BK-005 Situating the Conversation - Where This Inquiry Lives]].

## Summary
- A circumstance is a collection of events.
- A situation is the subset of circumstances that satisfies some description.
- Descriptions are connected in networks or webs. The network is what gives a description its reach.
- Open question: what schema should represent ordinary reality, and is schema.org adequate or too thin?

## Original wording
> "Circumstance as collections of events Situation subset of circumstances fulfilling or satisfied a description Description And the notion of networks or webs within each ... What schema to use to represent ordinary reality? Schema.org?"
- **Attribution:** the author
- **Source:** Obsidian Copilot chat, 2026-11-27, the author's brainstorm dump.
- **External references:** schema.org is an existing vocabulary, not yet checked against these classes.

## Real-world examples
- A flood as a circumstance made of events (rainfall, levee failure, evacuation). The situation is "homes uninsured in a flood zone", a subset that satisfies a description.

## Why it matters to the book
- A harm is always assessed within a situation. Without a formal situation class, the ontology cannot say which circumstances a harm belongs to.

## Open questions
- Is a situation a set of circumstances or a description that some circumstances satisfy?
- Can schema.org represent these, or does the book need its own vocabulary?
- How much of the network must be shown for a description to be meaningful?
