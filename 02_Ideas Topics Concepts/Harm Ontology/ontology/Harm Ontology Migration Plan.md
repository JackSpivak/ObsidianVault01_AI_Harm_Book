# Harm Ontology Migration Plan (v1/v2 → v3)

## Goals (from the author)
1. Don't lose existing work: examine every legal and philosophical class and property, and carry it into v3 wherever it enriches the model.
2. Don't lose existing narrative content: map and copy SKOS and Dublin Core annotations (definitions, notes, history notes, examples, altLabels, citations, provenance) to their new homes.
3. Generate new narrative content, and make sure explanations given in chat are written back into the ontology, so it documents itself.

## Principle
- **The `.ttl` file is the single source of truth.** Narrative lives in the ontology's annotations. The readable Compendium is **generated** from the `.ttl`, never edited by hand.
- An explanation counts as saved only once it's written into an annotation, with `dcterms:source` naming the session.

- **Trauma and attachment classes** → Effect kinds.
