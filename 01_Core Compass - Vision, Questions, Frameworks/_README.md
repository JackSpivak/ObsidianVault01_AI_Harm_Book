# Core - Vision, Questions, Frameworks

This folder houses the foundational compass of the vault: our high-level framings, core inquiries, principles, commitments, values, and long-term vision.

- **Principles & Commitments**: The immutable design rules and ethical stances we hold.
- **Core Questions & Inquiries**: The driving puzzles and deep investigations that structure our work.
- **Framings**: The mental models and lenses through which we view the problem space.
