# Participation Threshold and Distance from Harm

## Why this is distinct
- It asks how close an agent must be to a harm, along some axis or dimension, to count as a participant. The author calls this "a really critical decision". No existing card sets a threshold for participation.

## Anticipated direction
- Model distance along several axes at once: causal, network, temporal, informational and spatial.
- Distinguish perceptive distance (how far one can see) from effective distance (how far one's actions reach).
- Decide a threshold rule for participation and test it on edge cases.

## Conceptual territory
- Builds on [[Causal Chains - Occurrents, Participants and Completeness Validation]] and [[HO-I.a Factor and CausalRole]]. It adds distance and horizon as dimensions of participation.
- Uses network measures (centrality, density, small-world structure) as candidate metrics.

## Summary
- Participation is a matter of distance along one or more axes. A harm needs a rule for which nearby agents count as participants.
- Horizon is the farthest reach of the network one can see or affect from one's position. It sets how far an agent can be held responsible.
- "Think globally, act locally" suggests that an agent's local act can have distant effects, so local position does not settle participation.

## Real-world examples
- A supplier whose product is used in a harmful process many links downstream. Is it a participant?
- Bystanders in a crowd, or a shareholder in a company that causes harm, sit at different distances from the same event.

## Why it matters to the book
- If participation has no threshold, every agent is blamed and no one is. The threshold decides who is held to account.

## Open questions
- Which axis matters most for participation: causal, network or temporal?
- Is there a sufficient distance beyond which an agent is not a participant, or is participation always a matter of degree?
- How does a network centrality score translate into responsibility?
