# Harm as Setback to What Is Valued - Perspective Value Articulation

## Why this is distinct
- It makes the object of harm depend on what a perspective values. It also turns this into a testable requirement: a perspective is not admissible unless its values are articulated and formally identified.

## Anticipated direction
- Define harm as a setback to something someone has, needs, or whose access to it or execution of it is limited.
- Require each perspective to declare a value set. Without a declared set, no harm assessment from it can be settled.

## Conceptual territory
- Close to [[HO-II.a Assessment and Evaluative Standard]] and to [[HO-000 Harm as Perspective-Relative Assessment]]. This card adds the requirement that values be formally identified and testable.
- Links to [[Capability Approach - Sen and Nussbaum]], which lists capabilities as candidate valued objects.

## Summary
- Harm is a setback to something valued. Different perspectives value different things, so harm will look different from each.
- Capturing a perspective's core values is what makes harm assessable from it. A perspective without articulated values cannot be tested.
- This implies a testable frame: each perspective must have values written down, with identifiers, so that an assessment can be checked against them.

## Original wording
> "If harm is defined as a setback to something which somebody has or needs or limits access to or execution of etc etc then what's important is that it's harm to something that is valued. And different perspectives value different things. So it seems important to capture core values of a perspective to recognize or enable assessment of harm from that perspective. This also implies a testable frame that a perspective must have values articulated and formally identifiedIs"

## Real-world examples
- A bank's stated values (solvency, customer trust) versus a regulator's values (systemic stability). The same loss registers as harm to one and as a market correction to the other.
- Professional codes of ethics (medicine, law) that list the goods a profession protects. These are de facto value declarations.

## Why it matters to the book
- It explains why the book's assessments conflict. Harm disputes are often disputes about values that were never stated.

## Open questions
- What is the minimum set of values a perspective must declare before its assessments count?
- How are values identified formally (a controlled vocabulary, a value ontology, a signed statement)?
- Can a perspective's values change over time, and how is that recorded?
